PokéDesk 1.7.1 para Mac y 1.7.1-beta.1 para Windows.

- Nueve compañeros: Arcanine, Mewtwo, Pikachu, Charizard, Lucario, Gengar,
  Bulbasaur, Dragonite y Eevee.
- Dragonite incorpora movimientos articulares adaptados de su modelo original,
  con alas, cola, parpadeos y transiciones suaves.
- Eevee utiliza el modelo de nguyenlouis32: cabeza erguida, patas delanteras
  visibles y su tono café claro original. Nueve gestos con orejas, cola y caricias.
- Bulbasaur saluda con una pata y acompaña sus gestos con el movimiento del bulbo.
- Selector de nueve miniaturas 3D y colores propios para cada compañero.
- Se conservan calendario iCal, tareas, notas, timers y giro suave en reposo.

Mac: macOS 14 o posterior, Intel y Apple Silicon. Descomprime el ZIP y arrastra
PokeDesk.app a Aplicaciones. Esta edición está firmada localmente, sin Developer
ID ni notarización de Apple. Si macOS impide abrirla, después de intentarlo ve
a Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente.

Windows beta: Windows 10/11 de 64 bits. Usa el instalador EXE o extrae todo el
ZIP portátil y abre PokeDesk.exe. La beta no lleva firma digital.

Para actualizar, cierra la versión anterior desde su menú → Salir antes de
abrir la nueva. Se conservan los datos y ajustes de cada plataforma.
