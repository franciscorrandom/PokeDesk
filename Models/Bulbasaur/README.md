- SHA-256: `dbc54d890f094f80ec9366e3a1b90d7ae95b5160a0ad999505122ba9ca5a2f56`.

El original se conserva intacto. La biblioteca `Assets/bulbasaur-biblioteca.glb`
incluye nueve gestos, parpadeo, saludo, caricias, descanso y movimiento del bulbo.
Las lianas extendidas del ataque se ocultan para conservar la silueta de reposo.
Los apoyos de las patas se resuelven durante la preparación y quedan horneados
en los clips; no hay cálculo de IK en la app.

Regenerar: `python3 scripts/animate-bulbasaur.py` con NumPy para desarrollo.
Miniatura capturada con el renderizador nativo y `scripts/make-thumbnails.py`.
